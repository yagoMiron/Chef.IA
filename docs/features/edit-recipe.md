# F003 - Editar Receita

## Objetivo

Permitir alterações manuais ou assistidas por IA em qualquer receita cadastrada.

---

## Fluxo

1. O usuário abre uma receita.
2. O usuário escolhe:
   - editar manualmente;
   - solicitar alterações para a IA.
3. O sistema atualiza a receita.
4. As alterações são salvas localmente.

---

## Funcionalidades

### Edição Manual

Permite alterar qualquer campo da receita.

### Modificação por IA

O usuário descreve quais alterações deseja.

Exemplos:

- diminuir porções;
- trocar ingredientes;
- tornar mais saudável;
- reduzir custo.

---

## Regras

- O usuário sempre revisa o resultado antes do salvamento.
- Nenhuma alteração é aplicada silenciosamente.

---

## Critérios de Aceitação

- A receita pode ser editada manualmente.
- A IA consegue modificar receitas existentes.
