# F002 - Livro de Receitas

## Objetivo

Permitir que o usuário organize e consulte todas as receitas cadastradas.

---

## Fluxo

1. O usuário acessa o Livro de Receitas.
2. O sistema apresenta todas as receitas cadastradas.
3. O usuário pode pesquisar receitas.
4. O usuário seleciona uma receita.
5. O sistema abre a tela de detalhes.

---

## Funcionalidades

- Listar receitas.
- Pesquisar receitas.
- Abrir receita.
- Excluir receita.

---

## Regras

- As receitas devem permanecer armazenadas localmente.
- A pesquisa deve ocorrer em tempo real.
- A exclusão deve solicitar confirmação.

---

## Critérios de Aceitação

- O usuário encontra rapidamente qualquer receita.
- A lista permanece organizada.
