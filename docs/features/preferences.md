# F006 - Preferências Alimentares

## Objetivo

Permitir personalizar o comportamento da IA.

---

## Fluxo

1. O usuário abre Preferências.
2. O usuário descreve suas preferências.
3. O sistema salva o texto.
4. O contexto é enviado para a IA.

---

## Exemplos

- Evitar coentro.
- Preferir receitas baratas.
- Pouco óleo.
- Receitas fitness.
- Receitas italianas.

---

## Regras

As preferências são interpretadas pela IA.

Não haverá campos estruturados no MVP.

---

## Critérios de Aceitação

- O usuário consegue alterar as preferências livremente.
