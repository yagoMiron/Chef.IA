# F005 - Minha Geladeira

## Objetivo

Permitir que o usuário informe ingredientes disponíveis para personalizar receitas.

---

## Fluxo

1. O usuário abre "Minha Geladeira".
2. O usuário informa ingredientes.
3. O sistema salva as informações.
4. O contexto passa a ser utilizado pela IA.

---

## Exemplos

- Tenho ovos.
- Sempre tenho farinha.
- Nunca tenho manteiga.
- Tenho muito frango congelado.

---

## Regras

As informações são livres.

Não existe estrutura obrigatória.

A IA é responsável por interpretar o texto.

---

## Critérios de Aceitação

- O usuário consegue alterar o conteúdo a qualquer momento.
