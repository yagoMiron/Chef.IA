# ADR-002

## Título

Utilizar TypeORM

## Status

Aceito

## Contexto

Será necessário persistir dados em um backend futuramente.

## Decisão

Utilizar TypeORM.

Prisma não será utilizado.

## Motivos

- maior familiaridade da equipe
- preferência arquitetural
- menor dependência de geração de código

## Alternativas

- Prisma
- Drizzle
