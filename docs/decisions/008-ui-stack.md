# ADR-008 - UI Stack

## Status

Accepted

---

## Context

O projeto necessita de uma biblioteca de componentes consistente, acessível e facilmente customizável.

---

## Decision

A interface será construída utilizando:

- Tailwind CSS;
- shadcn/ui;
- Lucide Icons.

Os componentes do shadcn poderão ser personalizados conforme a identidade visual do projeto.

Não deverão ser utilizadas bibliotecas adicionais de componentes sem aprovação prévia.

---

## Objetivos

- consistência visual;
- acessibilidade;
- facilidade de manutenção;
- baixo acoplamento.

---

## Consequences

A maior parte da interface será construída sobre componentes reutilizáveis.

A identidade visual continuará totalmente controlada pelo projeto.
