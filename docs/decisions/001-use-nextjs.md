# ADR-001

## Título

Utilizar Next.js App Router

## Status

Aceito

## Contexto

O projeto precisa utilizar a arquitetura moderna do Next.js.

## Decisão

Será utilizado App Router.

## Consequências

### Positivas

- padrão atual
- melhor suporte
- layouts aninhados

### Negativas

- curva de aprendizado maior
- incompatibilidade com alguns tutoriais antigos

## Alternativas consideradas

- Pages Router
