# Identidade Visual

## Objetivo

Chef.IA deve transmitir a sensação de um livro de receitas moderno, organizado e acolhedor.

A interface deve parecer um aplicativo de culinária desenvolvido por profissionais, evitando características comuns de interfaces geradas automaticamente por Inteligência Artificial.

O foco principal é conforto visual durante a leitura de receitas.

---

# Conceitos

A identidade visual deve transmitir:

- simplicidade;
- organização;
- confiança;
- aconchego;
- culinária artesanal.

A experiência deve lembrar um caderno de receitas moderno, e não um sistema corporativo.

---

# Estilo

A interface deve ser:

- minimalista;
- elegante;
- limpa;
- discreta;
- consistente.

Evitar elementos puramente decorativos.

Toda informação deve possuir um propósito.

---

# Paleta de Cores

A identidade visual será inspirada nas cores da bandeira italiana, porém utilizando tons suaves e pastéis.

## Verde

Utilizado para:

- ações positivas;
- sucesso;
- confirmação;
- ingredientes;
- elementos naturais.

Preferir verdes suaves.

Exemplo:

- Sage
- Olive
- Mint

---

## Vermelho

Utilizado para:

- ações destrutivas;
- alertas;
- destaque de informações importantes.

Preferir vermelhos terrosos.

Evitar vermelho extremamente saturado.

---

## Branco

Cor predominante da aplicação.

Utilizar tons quentes.

Exemplos:

- Off White
- Ivory
- Cream

Evitar branco puro sempre que possível.

---

## Cores de apoio

Utilizar tons neutros para:

- bordas;
- divisórias;
- fundos secundários.

---

# Tipografia

## Texto

A tipografia principal deve priorizar:

- excelente legibilidade;
- leitura prolongada;
- aparência moderna.

Evitar fontes excessivamente decorativas.

---

## Títulos

Os títulos podem utilizar uma tipografia com personalidade, inspirada em livros de culinária ou restaurantes italianos, desde que mantenha boa legibilidade.

Essa fonte deve ser utilizada apenas para:

- títulos;
- cabeçalhos;
- destaques.

Nunca utilizar fontes decorativas em textos longos.

---

# Espaçamento

Utilizar um sistema consistente de espaçamento.

Evitar componentes excessivamente próximos.

A leitura da receita deve ser confortável.

---

# Bordas

Utilizar cantos levemente arredondados.

Evitar:

- cantos extremamente arredondados;
- aparência infantil.

---

# Sombras

Sombras devem ser discretas.

Utilizar apenas para criar separação visual.

Nunca utilizar sombras fortes apenas por estética.

---

# Ícones

Utilizar ícones simples e consistentes.

Os ícones devem complementar o texto.

Nunca substituir completamente textos por ícones.

---

# Componentes

Todos os componentes devem manter consistência visual.

Botões iguais devem possuir exatamente o mesmo estilo.

Inputs devem seguir um único padrão visual.

Cards devem utilizar o mesmo sistema de espaçamento.

---

# Responsividade

A interface será Mobile First.

Desktop e Tablet devem reutilizar os mesmos componentes sempre que possível.

---

# Acessibilidade

Todos os componentes devem respeitar boas práticas de acessibilidade.

É obrigatório:

- contraste adequado;
- foco visível;
- navegação por teclado;
- HTML semântico;
- suporte a leitores de tela quando aplicável.

---

# Princípios Visuais

Ao criar novas telas, sempre priorizar:

1. Legibilidade.
2. Simplicidade.
3. Consistência.
4. Organização.
5. Rapidez de uso.

Uma interface simples e consistente é preferível a uma interface visualmente chamativa.
