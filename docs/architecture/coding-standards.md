# Padrões de Código

## TypeScript

É proibido utilizar:

- any
- ts-ignore
- eslint-disable

---

## Componentes

Componentes devem possuir responsabilidade única.

---

## Hooks

Toda lógica reutilizável deve ser extraída para hooks.

---

## Serviços

Toda integração externa deve ficar em services/.

---

## Organização

Evitar arquivos excessivamente grandes.

Quando um arquivo crescer significativamente, considerar divisão.

---

## DRY

Antes de criar qualquer função nova, verificar se já existe implementação semelhante.

Duplicação de código não é aceita.

---

## SOLID

Sempre que aplicável, seguir princípios SOLID.

---

## Nomeação

Utilizar nomes claros e sem abreviações desnecessárias.

---

## Comentários

Comentários devem explicar "por quê".

Nunca explicar código óbvio.
